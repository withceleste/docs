# Providers

Celeste supports multiple AI providers through a unified interface.

## Available Providers

Import `Provider` from `celeste`.

```python
from celeste import Provider
```

- **`Provider.OPENAI`**: GPT-4o, GPT-Image, DALL·E.
- **`Provider.ANTHROPIC`**: Claude.
- **`Provider.GOOGLE`**: Gemini, Imagen.
- **`Provider.MISTRAL`**: Mistral.
- **`Provider.COHERE`**: Command.
- **`Provider.DEEPSEEK`**: DeepSeek.
- **`Provider.GROQ`**: Groq.
- **`Provider.MOONSHOT`**: Moonshot.
- **`Provider.XAI`**: Grok.
- **`Provider.BYTEPLUS`**: BytePlus.
- **`Provider.BFL`**: BFL.
- **`Provider.ELEVENLABS`**: ElevenLabs.
- **`Provider.GRADIUM`**: Gradium.

## Credentials

Celeste automatically loads API keys from environment variables.

| Provider | Environment Variable |
| :--- | :--- |
| OpenAI | `OPENAI_API_KEY` |
| Anthropic | `ANTHROPIC_API_KEY` |
| Google | `GOOGLE_API_KEY` |
| Mistral | `MISTRAL_API_KEY` |
| Cohere | `COHERE_API_KEY` |
| DeepSeek | `DEEPSEEK_API_KEY` |
| Groq | `GROQ_API_KEY` |
| Moonshot | `MOONSHOT_API_KEY` |
| xAI | `XAI_API_KEY` |
| BytePlus | `BYTEPLUS_API_KEY` |
| BFL | `BFL_API_KEY` |
| ElevenLabs | `ELEVENLABS_API_KEY` |
| Gradium | `GRADIUM_API_KEY` |

You can also pass keys explicitly when creating a client:

```python
from celeste import Provider
import celeste

response = await celeste.text.generate(
    model="gpt-4o",
    provider=Provider.OPENAI,
    api_key="sk-...",
    prompt="Hello from OpenAI",
)
```
