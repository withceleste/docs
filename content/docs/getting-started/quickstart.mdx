# Quick Start

This guide will help you make your first generation request with Celeste.

<Steps>
<Step>
## Install

Install Celeste:

```bash
uv add celeste-ai
```
</Step>

<Step>
## Configure Credentials

Set your API keys as environment variables. Celeste will automatically look for them.

```bash
export ANTHROPIC_API_KEY="sk-..."
export OPENAI_API_KEY="sk-..."
```

Or create a `.env` file:

```bash title=".env"
ANTHROPIC_API_KEY=sk-...
OPENAI_API_KEY=sk-...
```
</Step>

<Step>
## Use a domain namespace (recommended)

Import `celeste` and call the domain you work with. Domain is what you work with, not input or output.

```python
import celeste

# Domain: text
response = await celeste.text.generate(
    model="claude-sonnet-4-5",
    prompt="Explain quantum computing in one sentence.",
)
print(response.content)
```
</Step>

<Step>
## Generate Content

import { MethodSelector } from '@/components/MethodSelector';

Non-blocking I/O. Recommended for production apps and notebooks.

```python
response = await celeste.text.generate(
    model="claude-sonnet-4-5",
    prompt="Explain quantum computing in one sentence.",
    temperature=0.7,
```

Blocking I/O. Suitable for scripts and simple tools.

```python
    temperature=0.7,

print(response.content)
```

## Multi-Modal Example

Celeste uses the same interface for every domain and operation.

```python
import celeste

# Text domain → text output
text = await celeste.text.generate(
    model="claude-sonnet-4-5",
    prompt="Write a haiku about AI",
)

# Images domain → image output
image = await celeste.images.generate(
    model="gpt-image-1",
    prompt="A futuristic city at sunset",
)

# Videos domain → video output
video = await celeste.videos.generate(
    model="veo-3",
    prompt="Waves crashing on a beach",
)
```
