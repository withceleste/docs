Celeste supports Mistral's open-weights and commercial models.

## Credentials

Set the `MISTRAL_API_KEY` environment variable.

```bash
export MISTRAL_API_KEY="..."
```

## Text Generation

### Models

- `mistral-large-latest` (Default)
- `mistral-small-latest`
- `codestral-latest`

### Usage

```python
from celeste import create_client, Capability, Provider

client = create_client(Capability.TEXT_GENERATION, Provider.MISTRAL)
response = await client.generate(prompt="Hello Mistral")
```
