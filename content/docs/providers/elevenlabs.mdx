Celeste supports ElevenLabs for high-quality speech generation.

## Credentials

Set the `ELEVENLABS_API_KEY` environment variable.

```bash
export ELEVENLABS_API_KEY="..."
```

## Speech Generation

### Models

- `eleven_multilingual_v2` (Default)
- `eleven_turbo_v2`

### Usage

```python
from celeste import create_client, Capability, Provider

client = create_client(Capability.SPEECH_GENERATION, Provider.ELEVENLABS)
response = await client.generate(
    prompt="This voice is AI generated.",
    voice="Rachel" # Use voice ID or name
)
```
