Celeste supports Anthropic's Claude models for text generation.

## Credentials

Set the `ANTHROPIC_API_KEY` environment variable.

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

## Text Generation

### Models

- `claude-3-5-sonnet-20240620` (Default)
- `claude-3-opus-20240229`
- `claude-3-sonnet-20240229`
- `claude-3-haiku-20240307`

### Usage

```python
import celeste

response = await celeste.text.generate(
    model="claude-3-5-sonnet-20240620",
    prompt="Hello Claude",
)
```

### Thinking

Anthropic models support extended thinking parameters.

```python
response = await celeste.text.generate(
    model="claude-3-5-sonnet-20240620",
    prompt="Solve this complex logic puzzle...",
    thinking_budget=4096
)
```
