Celeste supports OpenAI's full suite of models, including GPT-4o for text, DALL-E 3 for images, and TTS for speech.

## Credentials

Set the `OPENAI_API_KEY` environment variable.

```bash
export OPENAI_API_KEY="sk-..."
```

## Text Generation

### Models

- `gpt-4o` (Default)
- `gpt-4o-mini`
- `gpt-4-turbo`
- `gpt-3.5-turbo`

### Usage

```python
import celeste

response = await celeste.text.generate(
    model="gpt-4o",
    prompt="Hello GPT-4o",
)
```

## Image Generation

### Models

- `dall-e-3` (Default)
- `dall-e-2`

### Usage

```python
import celeste

response = await celeste.images.generate(
    model="dall-e-3",
    prompt="A cute robot",
    quality="hd",
)
```

## Speech Generation

### Models

- `tts-1` (Default)
- `tts-1-hd`

### Usage

```python
import celeste

response = await celeste.audio.speak(
    model="tts-1",
    text="Hello world",
    voice="alloy",
)
```
