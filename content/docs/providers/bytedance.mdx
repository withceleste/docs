Celeste supports ByteDance's models via the BytePlus provider for video generation.

## Credentials

Set the `BYTEPLUS_API_KEY` environment variable.

```bash
export BYTEPLUS_API_KEY="..."
```

## Video Generation

### Models

- `pixeldance` (Default)

### Usage

```python
import celeste

response = await celeste.videos.generate(
    model="pixeldance",
    provider="byteplus",
    prompt="A panda eating bamboo",
    aspect_ratio="16:9",
)
```
