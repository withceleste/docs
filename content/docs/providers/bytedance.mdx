Celeste supports ByteDance's models (e.g., via Volcano Engine) primarily for video generation.

## Credentials

Set the `BYTEDANCE_API_KEY` environment variable.

```bash
export BYTEDANCE_API_KEY="..."
```

## Video Generation

### Models

- `pixeldance` (Default)

### Usage

```python
from celeste import create_client, Capability, Provider

client = create_client(Capability.VIDEO_GENERATION, Provider.BYTEDANCE)
response = await client.generate(
    prompt="A panda eating bamboo",
    aspect_ratio="16:9"
)
```
