Celeste supports Cohere's Command R series models.

## Credentials

Set the `COHERE_API_KEY` environment variable.

```bash
export COHERE_API_KEY="..."
```

## Text Generation

### Models

- `command-a-03-2025` (Default)
- `command-r7b-12-2024`

### Usage

```python
import celeste

response = await celeste.text.generate(
    model="command-a-03-2025",
    prompt="Hello Command R",
)
```
